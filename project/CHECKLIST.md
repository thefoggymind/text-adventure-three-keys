## 確認手順

以下の手順を上から順に実行してください。
各項目の確認が取れたら `[ ]` を `[x]` に変更してください。

### 1. Bot 起動確認

- [ ] **Render ダッシュボード** の Logs タブを開く
- [ ] 以下のログが出力されていることを確認する:
  ```
  ✅ Community Keeper 起動完了
     Bot名: Community Keeper
     BotID: <ID>
     サーバー数: 1
     ✅ スラッシュコマンド同期完了
  ```
- [ ] 上記のログが出ていない場合 → **トラブルシューティング**: 環境変数 `DISCORD_BOT_TOKEN` が正しく設定されているか確認する

---

### 2. スラッシュコマンド同期確認

- [ ] Discord クライアントで `/` を入力し、以下のコマンドが候補に表示されることを確認する:
  - `poll`, `poll_result`, `poll_list`
  - `remind`, `remind_in`, `reminders`, `cancel_reminder`
  - `rank`, `leaderboard`
  - `premium`, `premium config`
  - `moderation`, `moderation config`, `moderation keyword add`, `moderation keyword remove`, `moderation keyword list`
  - `export xp`, `export reminders`, `export config`, `export all`
- [ ] コマンドが表示されない場合 → 最大1時間待機後、Botを再起動（`on_ready()` で `await self.tree.sync()` が自動実行される）

### 3. ウェルカムメッセージ機能

#### 3.1 参加メッセージ
- [ ] 確認用の別アカウント（または Bot が管理するサーバーに未参加のアカウント）をサーバーに招待する
- [ ] システムチャンネルに以下のようなメッセージが送信されることを確認する:
  ```
  @usernameさん、ようこそ！ServerNameへ！
  ```
- [ ] **エッジケース**: Bot に `Send Messages` 権限がない場合、メッセージが送信されない（エラーも出ない）ことを確認する

#### 3.2 退出メッセージ
- [ ] メンバーがサーバーから退出する（またはキックされる）と、システムチャンネルに以下のメッセージが送信されることを確認する:
  ```
  usernameさんがサーバーを退出しました。
  ```

### 4. 投票/アンケート機能

#### 4.1 `/poll` 作成
- [ ] `/poll 質問:"好きな色は？" 選択肢:"赤" 選択肢:"青" 選択肢:"緑"` を実行する
- [ ] Embed メッセージが送信され、各選択肢にリアクション（1️⃣, 2️⃣, 3️⃣）が自動付与されることを確認する
- [ ] 各リアクションをクリックし、投票がカウントされることを確認する

#### 4.2 `/poll` オプション
- [ ] `/poll 質問:"期間限定投票" 選択肢:"案A" 選択肢:"案B" duration:60` を実行する
- [ ] 60秒後（または wait して）、投票が自動締切されることを確認する
- [ ] `/poll 質問:"匿名投票" 選択肢:"選択肢1" 選択肢:"選択肢2" anonymous:true` を実行する
- [ ] 投票者情報が記録されず、リアクション数のみカウントされることを確認する

#### 4.3 `/poll_result` 表示
- [ ] 作成された投票のIDを確認する（Embed フッターに表示）
- [ ] `/poll_result 投票ID:<ID>` を実行する
- [ ] 棒グラフ（`▬`）付きの結果 Embed が表示されることを確認する

#### 4.4 `/poll_list` 一覧
- [ ] `/poll_list` を実行する
- [ ] アクティブな投票一覧が Embed で表示されることを確認する

### 8. モデレーション機能

#### 8.1 `/moderation config` 設定（管理者・Premium必須）
- [ ] 管理者かつPremiumギルドで `/moderation config` を実行する
- [ ] 設定 Embed が返ってくることを確認する
- [ ] 非Premiumギルドではエラーになることを確認する

#### 8.2 `/moderation keyword add`
- [ ] `/moderation keyword add 単語:禁止ワード` を実行する
- [ ] 追加成功の Embed が返ってくることを確認する
- [ ] 同じ単語を再度追加すると重複エラーになることを確認する

#### 8.3 `/moderation keyword remove`
- [ ] `/moderation keyword remove 単語:禁止ワード` を実行する
- [ ] 削除成功の Embed が返ってくることを確認する
- [ ] 存在しない単語を指定するとエラーになることを確認する

#### 8.4 `/moderation keyword list`
- [ ] `/moderation keyword list` を実行する
- [ ] 登録済みのNGワード一覧が Embed で表示されることを確認する
- [ ] 空の場合は「登録されていません」と表示されることを確認する

#### 8.5 キーワードフィルター動作確認（Premiumギルドのみ）
- [ ] NGワードを1つ登録する（例: `禁止ワード`）
- [ ] 登録したNGワードを含むメッセージを送信する
- [ ] メッセージが自動削除されることを確認する
- [ ] 大文字/小文字の違いでもフィルターされることを確認する（該当する場合）

#### 8.6 スパム検出動作確認
- [ ] 短時間（5秒以内）に5回以上連続でメッセージを送信する
- [ ] スパムとして検出され、警告またはメッセージ削除が行われることを確認する
