# 「3つの鍵」— 運命を切り拓く、鍵はあなたの手の中に

> 公開URL: [https://thefoggymind.github.io/text-adventure-three-keys/](https://thefoggymind.github.io/text-adventure-three-keys/)

---

## 🎮 どんなゲーム？

**「3つの鍵」** は、森の中で目覚めたあなたが、選ぶ道ごとに異なる運命をたどるテキストベースアドベンチャーゲームです。

左の道か、右の道か──あるいは冒険をあきらめて帰るのか。あなたの選択が、6つの異なるエンディングへと物語を導きます。

インストール不要。ブラウザさえあれば、今すぐ冒険を始められます。

---

## 📖 ストーリーの魅力

ある朝、深い森の中で目を覚ましたあなた。目の前には **左の道** と **右の道** の分岐点。それぞれの道には、運命の勝敗が待ち受けています。

| 道 | 勝利 | 敗北 |
|----|------|------|
| 🍃 **左の道** | 清らかな川で回復し、輝く宝石を手に入れる | 毒された川の水で倒れる |
| 🏛️ **右の道** | 古代の宝具で富と名声を得る | 呪いで石になってしまう |

単なる二択ではありません。「周辺を探索する」という選択肢を選べば、隠された鍵と地図を手に入れ、**真の英雄** へと至る隠しエンディングへの道が開かれます。

そして、すべてのエンディングを巡ったとき、あなただけが知る物語の全貌が見えてくる──。

## 🏆 実績システム（全13種類）

ゲームをより深く楽しむため、**13種類の実績** を搭載しています。

| 実績 | 条件 | 難易度 |
|------|------|:------:|
| 🔰 はじまりの一歩 | 初めてゲームを開始する | ★ |
| 🚶 左の道を行く | 左の道を選択する | ★ |
| 🚶 右の道を行く | 右の道を選択する | ★ |
| 🏆 栄光の勝利 | いずれかのエンディングで勝利する | ★★ |
| 💀 無念の敗北 | いずれかのエンディングで敗北する | ★★ |
| 🏠 帰還 | 中立エンディング「帰還」に到達 | ★ |
| 🌟 真の英雄 | 隠しエンディングに到達 | ★★★ |
| 💎 収集家 | 全アイテムを収集する | ★★★ |
| 🗺️ 探検家 | 全6エンディングをコンプリート | ★★★★ |
| 🎮 常連プレイヤー | 合計10回プレイする | ★★ |
| 🍀 幸運の女神 | 勝敗判定で3回連続勝利 | ★★★ |
| 👁️ すべてを見通す者 | 全5エンディング（左勝利/敗北、右勝利/敗北、帰還）を閲覧 | ★★★★ |
| 👑 完全制覇 | 全13実績をコンプリート | ★★★★★ |

実績解除時は画面上部にポップアップが表示され、隠し実績は解除されるまで「???」と表示されます。すべての実績をコンプリートすると、**X（Twitter）で完全制覇をシェア** するボタンも出現。あなたの偉業を仲間に伝えましょう！

## 🕹️ 遊び方

1. [公開URL](https://thefoggymind.github.io/text-adventure-three-keys/) にアクセス
2. 「はじめる」ボタンをクリック
3. 表示された選択肢（`1`〜`4`）を選んで物語を進める
4. 全6エンディングを目指そう！

**便利な操作:**

| 操作 | 方法 |
|------|------|
| 選択肢を選ぶ | 画面上のボタンをクリック / キーボードの `1`〜`4` キー |
| セーブ | `💾 セーブ` ボタン / `S` キー |
| つづきから | タイトル画面の「つづきから」ボタン |
| テーマ切替 | 画面右上の `🌓` ボタンで Light / Dark 切り替え |
| 実績一覧 | タイトル画面の「🏆 実績」ボタン |

**Python版（CLI）はこちら:**  
`python game.py` で起動するCLI版も同梱されています。ターミナルでのプレイをお好みの方はこちらもどうぞ。
